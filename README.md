# ComposeGenAI
An AI-powered Android chat application built using Kotlin and Jetpack Compose.

This project is being developed as part of my journey to build production-ready Android applications with AI integration, modern architecture, and clean coding practices.

---
## Features

- Modern UI with Jetpack Compose
- MVVM Architecture
- StateFlow for UI state management
- Hilt Dependency Injection
- Clean Architecture (In Progress)
- Gemini AI Integration (Coming Soon)
- Streaming AI Responses (Planned)

---

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Hilt
- Coroutines
- StateFlow
- Clean Architecture
- Gemini AI
